# 天津中考全科复习App

面向天津初中生的中考全科复习工具（网页 / 手机 PWA）：

- 10 科知识点查找 / 诠释 / 举例：语文、数学、英语、物理、化学、道德与法治、历史、体育与健康、地理、生物
- 章节练习自动判分（错题自动入错题本）、真题仿真模考、智能“换一批新题”（按季度更新题库）
- 扫一扫 AI 判题讲题：已作答→先判对错再给思路+知识点；未作答→直接给答案；不限科目与题型（需在“我的→AI设置”填 Key）
- 错题本：按科目/知识点分类本地留存，一键导出 Word（可选含答案/不含答案）
- 英语计划性默写：默认“全部词库”约 2963 词/短语，每日词量可自拟，拍照/任意文件上传批改，次数统计与重点攻克清单
- 中考倒计时、学习报告、记忆复习
